# Bootcamp on Artificial Intelligence

Welcome to the **Bootcamp on Artificial Intelligence** repository! This repository contains all the code files, Jupyter Notebooks, and materials used during the bootcamp. Starting from data manipulation to advanced computer vision and natural language processing.

## 📚 Topics Covered


### 1. Data Manipulation & Visualization
*   **Libraries:** Pandas, NumPy, Matplotlib
*   **Concepts:**
    *   Working with DataFrames and CSV files.
    *   Data generation and simulation (e.g., Synthetic Cybersecurity User Behavior Analysis data).
    *   Data visualization using Matplotlib.

### 2. Machine Learning (Supervised & Unsupervised)
*   **Libraries:** Scikit-Learn (sklearn)
*   **Concepts:**
    *   **Regression:** Linear Regression for predicting continuous values.
    *   **Classification:** Decision Trees, Naive Bayes for categorical predictions.
    *   **Clustering:** K-Means clustering for grouping data.
    *   **Model Evaluation:** Train/test splits, accuracy scores, confusion matrices, and classification reports.

### 3. Natural Language Processing (NLP)
*   **Libraries:** NLTK (Natural Language Toolkit), WordCloud, Scikit-Learn
*   **Concepts:**
    *   Text tokenization and stopword removal.
    *   Generating Word Clouds to visualize text data.
    *   Text classification using `CountVectorizer` and `MultinomialNB` (Naive Bayes).

### 4. Computer Vision
*   **Libraries:** OpenCV (cv2)
*   **Concepts:**
    *   Basic image processing and manipulation.
    *   Reading, displaying, and transforming images using OpenCV.

### 5. Advanced Object Detection
*   **Libraries:** Ultralytics YOLO (You Only Look Once)
*   **Concepts:**
    *   Implementing state-of-the-art object detection models using YOLO.

## 📂 Repository Structure

*   `BootCamp*.ipynb`: Jupyter Notebooks containing the lessons, code snippets, and exercises for each session.
    *   *Includes specific notebooks for WordClouds, Machine Learning models, and OpenCV/YOLO implementations.*
*   `CSV_file.ipynb`: Notebook focused on handling and processing CSV datasets.
*   `.csv` files: Datasets used for training and testing the machine learning models (e.g., `user_login_analysis.csv`).

## 🚀 Getting Started

To run the notebooks locally, ensure you have Python installed along with the required libraries. You can install the dependencies using `pip`:

```bash
pip install numpy pandas matplotlib scikit-learn nltk wordcloud opencv-python ultralytics
```

Open the notebooks using Jupyter Notebook or JupyterLab to explore the code interactively!
